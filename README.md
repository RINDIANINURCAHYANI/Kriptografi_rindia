# 🔐 SKY-CRYPTO
### Simulasi Kriptografi Klasik Berbasis Flask

Aplikasi web modern untuk simulasi algoritma kriptografi klasik menggunakan Python Flask.  
Project ini dibuat untuk membantu mahasiswa memahami proses enkripsi dan dekripsi secara visual, edukatif, dan interaktif.

---

# ✨ Tampilan Aplikasi

UI dibuat dengan konsep:

- Modern Crypto Dashboard
- Clean UI
- Purple Neon Style
- Responsive Design
- Dark/Light Mode
- Visualisasi Matriks & Proses

---

# 🚀 Fitur Utama

## ✅ Algoritma Kriptografi

Aplikasi mendukung:

1. Caesar Cipher
2. Vigenère Cipher
3. Affine Cipher
4. Hill Cipher
5. Playfair Cipher
